# Checkbox

Checkbox lets users select zero, one, or multiple options from a list.
It is best used for independent choices where each option can be toggled on or off.

## UX Principles

### Use for independent selections
Choose checkbox when options are not mutually exclusive and users may select more than one.

### Write clear option text
Each option label should describe exactly what will be enabled or selected.

### Reflect selection state clearly
Keep checked and unchecked states obvious so users can quickly verify their choices.
