# Simple Select

Simple Select helps users choose exactly one option from a predefined list.
It is useful when users should pick from known values and when an editable text input is not required.

## UX Principles

### Use clear option labels
Option text should be short, unambiguous, and easy to scan.

### Provide sensible default selection
If a default is safe and expected, preselect it to reduce user effort.

### Keep placeholder meaningful
When no value is selected, placeholder text should clearly indicate what the user must select.
