# Radio

Radio allows users to select exactly one option from a small, mutually exclusive set.
Use radio when all available choices should remain visible to help quick comparison.

## UX Principles

### Keep options mutually exclusive
Each radio in the same group should represent one valid choice where selecting one deselects the others.

### Use concise and meaningful labels
Labels should clearly communicate the choice and be easy to scan.

### Provide a sensible initial state
Preselect a default option when a safe default exists, otherwise keep selection explicit.
